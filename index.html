04 · Projects

Things I've built

ApexDebugger

Python · Featured

A hybrid AI code reviewer for Salesforce Apex and Lightning Web Components — a deterministic rules engine paired with an LLM reasoning layer, gated by a hand-labeled golden eval set with F1 scoring. Its differentiator: it reasons across files, tracing user input from an LWC into the Apex controller it calls to catch injection bugs that live in the seam between them — a class of bug single-file linters can't see. Uses consensus voting across 3 LLM runs (keep findings in ≥2) and gives the deterministic layer final authority on the rules it owns, to suppress hallucinations. Deterministic layer currently scores 17/17 golden cases at 1.00 precision/recall.

Multi-Agent Dev Pipeline

Client Engagement · Featured

A ticket-to-PR orchestration system I built to speed up day-to-day development. It starts as a Claude skill — feed it a user story plus whatever notes a developer has, and an orchestrator agent takes it from there. An analysis agent (running on Opus, scoped to project-relevant files) reads the ticket and any related tickets or comments, asks up to three clarifying questions, checks Figma via MCP for UI work or keyword-searches the codebase for where the change likely lives, then chunks its findings. The orchestrator spins up dev agents per chunk — run in parallel or in sequence depending on whether the chunks depend on each other — with an opt-in Playwright test agent for large changes that loops fixes back to the dev agents on failure. Before anything ships, an architect agent reviews every changed file against rules defined in a memory file and can send work back for another pass. Only then does a PR agent commit the changes and open the pull request for human review.
